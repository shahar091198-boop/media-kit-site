# Media Kit — שחר אלפסי

אתר Media Kit חד-עמודי (Landing Page), בנוי HTML / CSS / JavaScript טהורים — בלי React, בלי בנייה (build step), בלי שרת. מתאים לאירוח חינמי ב-GitHub Pages.

## מבנה הפרויקט

```
media-kit-site/
├── index.html              כל התוכן והמבנה של האתר
├── css/
│   ├── variables.css        צבעים, פונטים, רדיוסים, מרווחים — שנו כאן כדי לשנות את כל האתר בבת אחת
│   ├── base.css              רספט, טיפוגרפיה בסיסית, כיווניות RTL
│   ├── layout.css            מבנה כל סקשן (Home / About / Reach / Case Studies / Brands / Contact)
│   ├── components.css        רכיבים חוזרים: עיגולי סטטיסטיקה, כרטיסי וידאו, מודאל הוידאו וכו'
│   └── responsive.css        התאמות למובייל
├── js/
│   ├── icons.js               כל האייקונים (SVG) של האתר, במקום אחד
│   ├── nav.js                  ניווט: גלילה חלקה, תפריט המבורגר במובייל, הדגשת פריט פעיל
│   └── lightbox.js             פתיחה/סגירה של נגן הוידאו (המודאל)
└── assets/images/            כל התמונות, מחולקות לפי סקשן
```

## איך מריצים את האתר במחשב שלכם

צריך רק שרת סטטי מקומי (לא Node, לא בנייה). אם יש פייתון מותקן (יש כמעט תמיד ב-Mac):

```bash
cd media-kit-site
python3 -m http.server 8811
```

ואז פותחים בדפדפן: `http://localhost:8811`

## עריכות נפוצות

### לשנות מספר עוקבים / סטטיסטיקה
כל המספרים כתובים ישירות בטקסט בתוך `index.html`. חפשו את המספר הישן (לדוגמה `6,616`) ותחליפו אותו — הוא מופיע גם בעמוד הבית וגם בסקשן הפלטפורמה הרלוונטית (Instagram / TikTok / YouTube), אז כדאי לחפש את כל המופעים.

### להחליף תמונה
כל התמונות נמצאות ב-`assets/images/<תיקיית-סקשן>/`. שימרו על אותו שם קובץ כדי לא לצטרך לגעת ב-HTML, או עדכנו את הנתיב ב-`index.html` בהתאם. מומלץ תמונות עד ~1500px בצלע הארוכה (איכות מספיקה למסך, בלי להכביד על זמן הטעינה).

### להוסיף / להחליף סרטון בפורטפוליו
כל כרטיס וידאו בקובץ `index.html` נראה כך:

```html
<button class="video-card__cover" data-video-trigger
        data-youtube-id="XXXXXXXXXXX"
        data-video-title="שם הסרטון">
  <img src="assets/images/videos/cover-שם.jpg" alt="...">
  ...
</button>
```

כדי להחליף סרטון: משנים את `data-youtube-id` למזהה הסרטון החדש ביוטיוב (החלק שאחרי `/shorts/` בקישור), מחליפים את תמונת הקאבר, ומעדכנים את הכותרת והתיאור בטקסט שמתחת. הסרטון ייפתח בתוך חלון (מודאל) מעל האתר, בלי להוציא את הגולש לעמוד אחר.

### להוסיף / להסיר מותג בסקשן Brands
בתוך `index.html`, בתוך `<ul class="brand-flower">`, כל מותג הוא פריט `<li>` עם לוגו וטקסט. כדי להוסיף מותג חדש למובייל בלבד (בלי לשבור את פריסת ה"פרח" בדסקטופ) מומלץ להיעזר בכלי כמו קלוד קוד — זו עריכה שדורשת גם תוספת ב-CSS.

### פרטי הקשר (Contact)
האימייל, הטלפון ולינק האינסטגרם נמצאים גם בתחתית עמוד הבית וגם בסקשן Contact, בתוך `index.html`. חיפוש-והחלפה של הערך הישן מספיק.

## הערות טכניות חשובות

### פונטים
עיצוב ה-PDF המקורי משתמש בשני פונטים בתשלום: **The Seasons** (כותרות) ו-**TT Norms Pro** (טקסט UI). מכיוון שאין רישיון web-font לפונטים האלה, האתר משתמש בתחליפים חינמיים דומים ויזואלית: **Cormorant Garamond** ו-**Inter** (מוגדרים ב-`css/variables.css`, במשתנים `--font-display` ו-`--font-ui`). שני הפונטים העבריים (**Cardo** לכותרת השם ו-**Noto Sans Hebrew** לטקסט) הם הפונטים המקוריים המדויקים מה-PDF, כי הם חינמיים.

אם בעתיד תרכשו רישיון web-font ל-The Seasons / TT Norms Pro — צריך להוסיף את קובצי ה-woff2 לתיקייה חדשה (`assets/fonts/`), להגדיר `@font-face` ב-`css/base.css`, ולעדכן את המשתנים ב-`variables.css`.

### רקע הטקסטורה
הרקע הבז' המחוספס (`assets/images/texture-paper.jpg`) הוא תמונת הרקע המקורית מה-PDF עצמו — לא שוחזר, אלא חולץ ישירות מהקובץ.

### אייקון פייסבוק
בפוטר של עמוד הבית יש אייקון פייסבוק שכרגע לא מקושר לשום עמוד (אין handle של פייסבוק ב-PDF המקורי). לינק ל-`href="#"` ב-`index.html`, בתוך `.home__footer-icons`. אפשר לעדכן בקלות כשיהיה קישור.

### לוגואי מותגים ברזולוציה נמוכה
לוגואי המותגים בסקשן Brands חולצו מה-PDF ברזולוציה נמוכה יחסית (כ-200px). אם יש לכם קבצי לוגו מקוריים באיכות גבוהה יותר, כדאי להחליף אותם ב-`assets/images/brands/`.
